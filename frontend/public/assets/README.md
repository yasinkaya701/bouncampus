# BOUNCAMPUS visual assets

Original vectors for the BOUNCAMPUS web UI. These are intentionally editorial/diagrammatic rather than copies of university photography.

| Asset | Purpose | Current use |
| --- | --- | --- |
| `bouncampus-hero.svg` | South Campus + Bosphorus + digital-layer hero artwork | Home overview |
| `campus-topography.svg` | Repeating contour/topography texture | Global footer |
| `building-placeholder.svg` | Neutral building-card / empty-state visual | Available for building cards and detail pages |
| `map-pin-academic.svg` | Academic-building map marker | Available for Leaflet/Cesium marker work |

## Palette

- Canvas: `#f6f6f1`
- Navy: `#102a43`
- Blue: `#173f67`
- Bosphorus accent: `#7ea7bb` / pale blue tints
- Landscape accent: muted green (`#6f8b73` family)

## Rules

- Keep source-provenance UI visually distinct from decorative artwork.
- Do not treat these illustrations as geospatially exact maps or measured campus geometry.
- Prefer SVG for flat illustrations and markers; use WebP/AVIF for future photographic/raster assets.
- Preserve accessible labels when an asset conveys information; decorative textures should remain presentation-only.
