## Why binaries are not mirrored by default

A cumulative hub should stay reproducible **and** legally clean.

Mirror a third-party PDF/image into the repo only when:
1. the license clearly permits redistribution;
2. provenance and license are stored;
3. the local copy adds real resilience/value;
4. file size is appropriate for git.

Otherwise store the canonical landing URL and direct download URL here.

## Agent retrieval rule

Before relying on a numeric/current claim:
- re-open the canonical source;
- record access date;
- retain the artifact URL/version;
- capture exact scope/units;
- note any source inconsistency;
- never silently “repair” authoritative source values.
