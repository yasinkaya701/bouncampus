# Competitor Capability Matrix — 2026-10-04

**Purpose:** Prevent unsupported novelty claims and identify differentiation hypotheses worth testing through PMR.  
**Status:** Public vendor-source research. Vendor performance claims are not neutral benchmarks and must not be reused as expected BOUNCAMPUS outcomes.

---

# Executive conclusion

BOUNCAMPUS cannot defensibly differentiate on any of the following alone:

- AI;
- food-waste measurement;
- plate-waste vision;
- production guidance;
- demand forecasting;
- sustainability dashboards;
- evidence/audit trails;
- GreenMetric/THE-aligned campus reporting.

The stronger differentiation hypothesis is a narrower **university operational decision-and-verification layer** built around:

```text
university-specific context
+ exact decision/freeze timing
+ source semantics / provenance
+ explicit uncertainty / WITHHOLD
+ human approval / override
+ action-to-outcome verification
```

This is still a **hypothesis**. Buyers must compare it against current tools and workflows.

# 1. Winnow — direct food-waste/forecasting overlap

Winnow's university pages publicly describe:

- automated food-waste capture;
- `Throw & Go` identification/recording;
- `VisionPW` plate-waste measurement using a motion-sensor camera;
- production guidance through academic/term-time demand swings;
- service/category/site exports with cost and CO2e context.

Sources:

- https://www.winnowsolutions.com/industries/universities
- https://www.winnowsolutions.com/industries/universities/sustainability
- https://www.winnowsolutions.com/industries/universities/fb

## September 2026 — Winnow Foresight

Winnow announced **Winnow Foresight** on 29 September 2026.

Public launch materials say it:

- is mobile-first;
- predicts kitchen demand;
- produces daily/item-level production plans;
- uses guest occupancy + waste data;
- requires no extra hardware for the forecasting app;
- was developed with Hilton chefs;
- initially targets focused-service hotels / lighter F&B footprints.

Sources:

- https://www.winnowsolutions.com/resources/news/winnow-and-hilton-announce-winnow-foresight-a-mobile-first-ai-powered-forecasting-tool-designed-to-predict-kitchen-demand-and-prevent-food-waste
- https://www.winnowsolutions.com/resources/news/introducing-winnow-foresight-a-new-way-to-prevent-food-waste-and-improve-guest-satisfaction-with-ai-powered-forecasting

### Implication

Do **not** claim:

- "existing food-waste tools only measure after waste occurs";
- "we are the first to forecast how much a kitchen should produce";
- "forecasting is our moat".

### Gap worth testing

Winnow's current public university messaging emphasizes waste observations and production guidance; Foresight's launch messaging is explicitly hotel/focused-service oriented.

A buyer interview should test whether a university-specific layer adds value through:

- academic calendar/service-regime representation;
- campus/channel allocation;
- institutional card/turnstile context;
- contractor/university shared workflow;
- procurement/payment semantics;
- uncertainty + abstention;
- intervention verification tied to institutional evidence governance.

Do not state Winnow lacks these capabilities unless directly verified.

# 4. Existing internal workflows are a major competitor

The strongest alternative may be neither Winnow nor Emissary.

Potential status-quo stack:

- experienced production manager;
- same-weekday or trailing averages;
- contractor planning sheet;
- Excel / Google Sheets;
- existing ERP/POS/turnstile exports;
- menu/calendar announcements;
- manual buffer;
- existing BMS/BEMS for non-food domains;
- annual sustainability reporting workflow.

### PMR rule

Every interview should ask:

> **"What did you use the last time you decided tomorrow's quantity?"**

not:

> "Which software competitor do you use?"

A manually maintained workflow can be the incumbent that is hardest to displace.

# 6. Competitive interview questions

For a university/operator using any existing software or structured workflow:

1. What system did you use for the last production decision?
2. What decision does it actually change?
3. When in the workflow does its output arrive?
4. What does it fail to know about your campus/contract/service?
5. What still requires manual judgement?
6. How do you know whether following the recommendation worked?
7. What would cause you to ignore it?
8. Which data must staff enter manually?
9. How difficult is integration/procurement/training?
10. Would a new tool replace something or need to sit on top of it?

The goal is not to make the interviewee rank product ideas. The goal is to expose the unresolved job.

# 8. Product strategy consequence

Avoid building a feature-by-feature copy of mature food-waste vendors.

The research priority is to prove whether the **institution-specific decision gap** exists:

```text
Who decides?
When?
Using what data?
What still requires judgement?
What is the cost of being wrong?
Which existing system is already in the loop?
What outcome would prove the new decision was better?
```

If existing systems already solve this sufficiently, BOUNCAMPUS should not compete head-on; it should either integrate, move to a different decision gap, or narrow to a missing institutional coordination/verification problem.
