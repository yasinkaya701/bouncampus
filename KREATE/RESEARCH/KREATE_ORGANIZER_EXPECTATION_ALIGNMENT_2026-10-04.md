
# 2. Assignment gate

Organizer material describes the assignment around four items:

1. **Problem** — define the climate problem clearly.
2. **Customer** — identify who experiences or owns the problem.
3. **PMR** — show what was learned from primary market research.
4. **Solution** — explain the solution to develop **building on PMR**.

### Critical interpretation

Solution wording should be downstream of PMR.

If interviews show that the reachable decision is:

- campus allocation instead of total production;
- second-batch release instead of prior-day forecast;
- portion size instead of demand quantity;
- menu/quality instead of production surplus;

then the final solution should change accordingly.

Keeping the original solution despite contradictory PMR would be weaker against the organizer's stated learning model.

# 5. Strong value proposition means more than climate language

The organizer explicitly asks for a strong value proposition.

For BOUNCAMPUS this should not default to:

> save the planet with AI.

The value unit must match the operational persona's ranked priority.

Possible PMR-tested value units include:

- fewer edible surplus portions/kg per service;
- lower ingredient/production cost where the buyer captures it;
- fewer early sellouts / emergency substitutions;
- lower planning time/manual reconciliation burden;
- better auditability of university-contractor decisions;
- measurable sustainability evidence.

Which one leads the pitch remains `UNKNOWN` until PMR.

# 6. Application red-team against organizer language

A weak submission would show:

```text
lots of product features
+ broad campus vision
+ generic customer
+ simulated impact
+ interviews asking whether people like the idea
```

A stronger submission follows the organizer's actual sequence:

```text
specific repeated problem
+ named person/decision
+ real incident evidence
+ assumptions that changed
+ narrowed PMR-driven solution
+ concrete value metric
```

---

# 7. Research stop rule

Secondary research is useful only if it:

- changes who should be interviewed;
- changes what hypothesis should be tested;
- prevents an unsupported claim;
- clarifies a competitor/current alternative;
- clarifies value/buyer/measurement mechanics.

It must not replace the organizer's explicit expectation for direct user/stakeholder evidence.
